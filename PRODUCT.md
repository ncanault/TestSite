# Product

## Platform

web

## Users

Primary: an **alliance leader** in the mobile game Evony — typically the player who
registers, creates their alliance (trigram + name + server), subscribes, and does the
recurring work of entering/updating their roster's stats. They manage this mostly on
**desktop**, even though the game itself is played on mobile — data entry and analysis
(tables, charts, Hive Composition) are treated as a desktop-first workflow; mobile stays
fully supported but is not the primary design target.

Secondary: other members of the alliance, who may view the dashboard but do not
necessarily enter data themselves. An **admin** role (platform operator, not an alliance
member) manually links players to alliances and activates subscriptions.

## Product Purpose

A subscription SaaS dashboard for Evony alliances: create your alliance for free, then
subscribe to track your roster's accounts (power, Keep, attack/defense buffs), see its
evolution over time, and plan combat composition (Setter selection, Hive Composition
placement).

## Positioning

Intended as a public, multi-alliance product — not a private tool for one alliance —
that any Evony alliance can sign up for and pay to use. What it offers that a shared
spreadsheet or a Discord bot doesn't, in order of importance:

1. **Computed strategy tools**, not just data storage: the Setter is derived
   automatically from normalized Attack Score + Rally Capacity, and the Hive Composition
   board is generated by a Euclidean-distance placement algorithm around the Setter —
   calculations no spreadsheet does natively.
2. **Automatic historization**: every save of an account's stats is appended to a
   history table with no extra effort, powering evolution-over-time charts a manually
   maintained spreadsheet would need discipline to reproduce.
3. **No setup required**: a ready-to-use interface instead of a shared spreadsheet
   someone has to maintain, or a bot someone has to configure and host.

## Operating Context

- A player registers (email/password), then either creates an alliance for free
  (trigram + name + server — the server is created on the fly if new) or waits for an
  admin to link their account to an existing alliance.
- Entering/tracking account data (the Team page) requires an alliance with an **active**
  subscription. Subscriptions are **cumulative**: Basic ⊂ Alliance ⊂ Competitive — each
  tier unlocks its page plus everything below it.
- Payment is a manual PayPal link + a "request activation" step; an admin verifies the
  payment and activates the subscription by hand from a back-office. There is no live
  PayPal webhook/API integration yet.
- Only the alliance's creator (owner) can request/pay for a subscription.

## Capabilities and Constraints

- An `Account` (an in-game player's profile the alliance tracks) is identified by its
  **unique in-game account number** — the platform's primary key for that record, not an
  internal id. An account belongs to **exactly one alliance at a time, platform-wide**:
  re-registering an account number already owned by a different alliance is rejected.
  There is currently no history of an account moving between alliances — a transfer
  means removing it from the old alliance and re-adding it to the new one.
- An `Alliance` is identified by a 3-character trigram + a name, both unique **per
  server** (not globally — the same trigram can exist on two different servers, matching
  the real game). `Server` is a first-class shared entity, not free text.
- Undecided / open: whether real PayPal Subscriptions (webhooks, automatic
  activation/cancellation) will replace the manual admin-activation flow.

## Brand Commitments

Product name: **Evony Alliance Dashboard**. An earlier working name/branding,
"SOG#669" (the operator's own alliance), was deliberately generalized away from the
navbar/footer/title so the product reads as a product for any alliance, not one
alliance's private tool.

## Evidence on Hand

The scoring formulas (Attack/Defense Score, Setter selection, Hive Composition placement
algorithm) and the dark "war room / command center" gold-accent visual language both
originate from a prior single-file HTML dashboard the operator built and used for their
own alliance (SOG#669) — provided as a detailed reproduction spec and treated as
authoritative reference for both the math and the established visual identity. No
customer testimonials, case studies, or real payment data exist yet; this is pre-launch.

## Product Principles

1. **Computed strategy over manual bookkeeping** — every derived metric (Setter, Hive
   Composition, Attack/Defense Score) is calculated automatically from raw stats, never
   left to the player to work out by hand.
2. **Historization by default** — every data save is preserved automatically, so
   evolution over time is always available without any extra effort from the user.
3. **Progressive depth via subscription tiers** — Basic tracks, Alliance analyzes trends,
   Competitive optimizes composition; each tier is a genuine capability upgrade, not an
   arbitrary paywall on the same feature.
4. **Desktop-first workflows, mobile-compatible** — data entry and deep analysis targets
   desktop first; nothing breaks on mobile, but it is not the primary design target.
5. **Low-friction onboarding** — free alliance creation and a simple manual PayPal +
   admin-activation flow, so a new alliance gets value before any complex payment
   integration is needed.
